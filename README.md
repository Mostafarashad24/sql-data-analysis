# SQL Data Analysis

## Project Overview

This project analyzes a cleaned e-commerce orders dataset using SQL. The analysis examines order values, product performance, order statuses, payment methods, referral sources, coupon usage, annual revenue, and high-value orders.

The SQL analysis is documented in Microsoft Excel, where each query has a corresponding result and the project includes a dedicated Key Insights section. The complete SQL queries are also provided in the project `.sql` file.

## Objectives

- Inspect the order data using SQL.
- Identify high-value orders.
- Compare products by order count, quantity sold, average unit price, and revenue.
- Analyze order value and revenue across order statuses.
- Compare average order value by payment method and coupon group.
- Analyze revenue generated by referral sources.
- Identify order-status groups with an average order value above 1,000.
- Summarize product performance using multiple aggregations.
- Examine annual order and revenue trends.
- Identify products generating more than 150,000 in revenue.
- Find the 10 highest-value orders.

## SQL Analysis

The project contains 15 SQL analysis queries. The queries demonstrate the following SQL operations where applicable:

- `SELECT`
- `WHERE`
- `ORDER BY`
- `GROUP BY`
- `COUNT`
- `SUM`
- `AVG`
- `HAVING`
- `LIMIT`

The analysis uses the `orders` table and focuses primarily on aggregating and comparing order information across different business dimensions.

## Analysis Queries

| # | Analysis Question | SQL Approach | Key Result / Insight |
|---|---|---|---|
| Q1 | Inspect the first 10 orders | `SELECT` + `LIMIT` | Returns selected order, product, quantity, unit price, and total price fields for the first 10 rows. |
| Q2 | Which orders have a total price above 2,000? | `WHERE` + `ORDER BY` | Returns high-value orders above 2,000, sorted from highest to lowest total price. |
| Q3 | How many orders are associated with each product? | `GROUP BY` + `COUNT` | Printer has the highest order count with 181 orders. |
| Q4 | How many units were sold for each product? | `GROUP BY` + `SUM` | Chair has the highest total quantity sold with 562 units. |
| Q5 | What is the average unit price for each product? | `GROUP BY` + `AVG` | Phone has the highest average unit price at 375.22. |
| Q6 | What is the total revenue generated by each product? | `GROUP BY` + `SUM` | Chair generates the highest product revenue at 195,620.11. |
| Q7 | How do order statuses compare by order count and total value? | `GROUP BY` + `COUNT` + `SUM` | Cancelled orders have the highest total value at 276,396.21. |
| Q8 | How does average order value differ by payment method? | `GROUP BY` + `COUNT` + `AVG` | Credit Card has the highest average order value at 1,127.55. |
| Q9 | Which referral source generates the most revenue? | `GROUP BY` + `COUNT` + `SUM` | Instagram generates the highest revenue at 275,285.45. |
| Q10 | How does average order value differ by coupon group? | `GROUP BY` + `COUNT` + `AVG` | FREESHIP has the highest average order value at 1,070.41. |
| Q11 | Which order statuses have an average order value above 1,000? | `GROUP BY` + `AVG` + `HAVING` | Cancelled, Pending, Delivered, and Shipped meet the condition. |
| Q12 | What is the overall product performance? | `COUNT` + `SUM` + `AVG` + `GROUP BY` | Chair has the highest revenue, while Laptop has the highest average order value at 1,110.56. |
| Q13 | How do orders and revenue change by year? | `GROUP BY` + year extraction + `COUNT` + `SUM` | 2023 records the highest orders and revenue: 510 orders and 552,643.24 revenue. |
| Q14 | Which products generate more than 150,000 in revenue? | `GROUP BY` + `SUM` + `HAVING` | All seven products in the result exceed 150,000 in revenue. |
| Q15 | What are the 10 highest-value orders? | `ORDER BY` + `LIMIT` | Returns the 10 orders with the highest `TotalPrice`; the highest is ORD200789 at 3,456.40. |

## Key Insights

The main findings documented in the workbook include:

- Chair is the highest-revenue product with total revenue of 195,620.11.
- Chair also has the highest total quantity sold with 562 units.
- Phone has the highest average unit price at 375.22.
- Instagram is the highest-revenue referral source with 275,285.45 in revenue.
- Credit Card has the highest average order value among payment methods at 1,127.55.
- FREESHIP has the highest average order value among coupon groups at 1,070.41.
- The `HAVING` analysis identifies four order-status groups with an average order value above 1,000: Cancelled, Pending, Delivered, and Shipped.
- Annual analysis shows that 2023 had the highest number of orders and revenue, with 510 orders and 552,643.24 in revenue.
- The product revenue analysis shows Chair and Printer generating almost the same total revenue: 195,620.11 and 195,612.61 respectively.
- The highest-value order identified is ORD200789, a Tablet order with a `TotalPrice` of 3,456.40.

The completed analysis uses SQL to examine the e-commerce order dataset from several business perspectives.
